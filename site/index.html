Can a language model design to spec?

Models get engineering design tasks in digital signal processing, electronics and control. Every answer is graded by measurement or simulation (scipy, python-control, ngspice), never by another model, and every attempt can be opened and checked below.

No model has been run yet. The two rows below are each task family's reference design and its known-bad answer, graded exactly like model answers. They show how the grading and the attempt viewer work.

Method

  • No model as judge. Answers are graded by deterministic measurement or simulation.
  • Seeded tasks. The dev set is public; the test set is hidden and drawn again for every benchmark version.
  • Continuous score and pass/fail. Each requirement gives a ratio that reaches 1 exactly when it is met; the score is the smallest one.
  • Format errors count separately, so "cannot design it" and "cannot follow the answer format" stay apart.
  • One prompt for every model. Sampling settings are stored with every attempt, and raw transcripts are published.
  • Conflict of interest. The project is built with help from Claude, and Claude models are evaluated. Task difficulty is set by rules about design methods, never by any model's score.

Details, code and the full rules are in the repository.

margin-bench is an open benchmark. Results can be reproduced with the code and run configs in the repository.
